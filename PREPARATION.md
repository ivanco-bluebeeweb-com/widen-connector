# Widen (Acquia DAM) Connector — Preparation

**Category:** C43. Digital Asset Management (DAM)  
**Vendor URL:** https://widen.com  
**Preparation status:** Specification & Architecture Validated  
**API Documentation Reference:** Vendor Primary API Standard

## 1. Product passport
Коннектор **Widen (Acquia DAM)** интегрирует платформу Imperal Cloud с официальным API сервиса для автоматизации задач в категории **C43. Digital Asset Management (DAM)**. Он предоставляет безопасный интерфейс к проверенным операциям вендора без использования синтетических шаблонов.

## 2. Человеческая проблема
Когда **контент-менеджер** сталкивается с задачей: **корпоративное управление цифровыми активами, контроль версий контента и интеграция с PIM/CMS экосистемами**, возникает необходимость ручного переключения между интерфейсами, что замедляет работу и увеличивает риск операционных ошибок. Коннектор Widen (Acquia DAM) переносит ключевые сценарии управления прямо в экосистему Imperal.

## 3. Роли и права доступа
- **контент-менеджер, директор по маркетинговым технологиям**: основные пользователи, управляющие бизнес-процессами.
- **Владелец рабочей зоны / Администратор**: отвечает за подключение коннектора и выдачу доступов.
- **Оператор Imperal**: выполняет действия только в рамках полномочий, разрешенных API-ключом вендора.

## 4. Первичный сценарий и границы
Основной сценарий: `поиск ассета по артикулу товара -> проверка срока действия прав на контент -> скачивание необходимого рендишена`.

**Границы применимости:**
- Коннектор не хранит мастер-пароли и учетные данные третьих сторон.
- Любые необратимые или тарифицируемые операции требуют подтверждения.
- Соблюдаются лимиты запросов (rate limits) сервиса Widen (Acquia DAM).
